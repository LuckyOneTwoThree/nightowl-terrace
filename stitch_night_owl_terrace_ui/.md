## 一、项目概述

### 定位与要解决的问题

五大联赛全季约 1,752 场比赛，分散在 5 个联赛、多个转播平台与多个开球时档。核心场景是微信群里的球迷小圈子，需要在 3 秒内回答两个问题：**今天有什么球、今晚该熬哪一场**；在此之上，用多人玩法维持整个赛季的参与感，并在赛季末沉淀为小圈子的共同记忆。

### 核心交付

**微信小程序**：体验版发布，免上架审核；云开发承载数据与多人结算，无自有服务器、无自有账号体系。单文件 HTML 保留为离线备份与逻辑原型。

### 设计总原则

1. 首屏永远先回答「今晚看什么」。
2. 推荐 = 看点 ÷ 睡眠成本——熬夜是稀缺资源，推荐系统必须会算账。
3. 1,752 场不是散装赛程表，是一部可追的连续剧。
4. 多人互动以云数据库为唯一事实源，群内接龙通过分享卡片参数完成。
5. 产品的人格（夜猫解说、冷知识）决定朋友是否愿意每天打开。

### 明确不做（v1）

实时比分直播（比分随数据更新补入后自动结算）、直播源聚合、自有账号体系（直接用微信身份）、公开上架（走体验版）。

## 四、产品架构

移动端 5 个 Tab，直接映射小程序 tabBar：

|Tab|内容|
|---|---|
|今日|今晚之选 Hero 卡（倒计时＋看点＋夜猫指数＋海报导出）；今日加餐；明日预告；「正在追的剧」故事线横滑区；无球日降级（下一场倒计时＋补番推荐）|
|本周|夜猫指数预算面板（额度＋最优组合＋备选）；跨联赛焦点 Top 5–8；雷区预警；修仙场（凌晨档）专区|
|赛程|日历视图（主，日期主键）／轮次视图（次）；联赛与星级筛选；时间待定标注；已赛场次随数据更新补比分|
|玩法|盲评猜球（本周竞猜单＋周榜／总榜）；夜猫榜（修仙打卡）；德比法庭；盲盒开球|

故事线详情页（时间轴）从比赛卡徽标或「正在追的剧」进入，不占独立 Tab。日历视图以日期为主键而非轮次——德甲、法甲为 18 队 34 轮，与英超轮次编号不对齐，按轮次组织会错位。

## 五、数据架构

四层分离。全量赛程由机器生成，人工只维护推荐层与故事线层——这是 1,752 场规模下唯一可持续的方式。

### 1. 球队字典（96 条，定义一次）

```json
{ "id": "ARS", "zh": "阿森纳", "en": "Arsenal", "league": "PL", "color": "#EF0107" }
```

### 2. 赛程层（约 1,752 条，机器生成，无看点）

```json
{ "l": "PL", "r": 1, "t": "2026-08-22T03:00", "tbd": false, "st": "sched", "h": "ARS", "a": "COV", "s": 3, "sc": null, "tv": null }
```

`t` 为北京时间（主键，固定 Asia/Shanghai，不带时区标记，全年无歧义）；`st` 为场次状态（sched 未赛／done 已赛／pp 延期，延期场在日历原位标注）；`tbd` 标记开球时间待定；`s` 为睡眠成本档位（见第六节）；`sc` 为赛后补录的比分（如 `"2-1"`），是盲评猜球与德比法庭自动结算的数据源；`tv` 为转播平台预留字段。单条约 150 字节，全季合计 300KB 量级。

### 3. 推荐层（约 250–300 条／季，人工维护）

```json
{
  "m": "PL-1-ARS-COV",
  "star": 3,
  "story": ["ARS_TITLE_DEFENSE"],
  "points": ["卫冕冠军赛季首战", "考文垂重返顶级联赛"],
  "trivia": "考文垂上次踢顶级联赛时，英超还没有 VAR",
  "replay": true,
  "avoid": false,
  "upset": false
}
```

只覆盖焦点战；`trivia` 为可选的每日冷知识字段，供夜猫絮语使用；`upset` 为冷门预警标记（人工维护：纸面实力明显占优方若不胜即算冷门），是盲评猜球「冷门翻倍」的唯一判据，保证判据可复算。

### 4. 故事线层（约 12–18 条／季）

```json
{
  "id": "ARS_TITLE_DEFENSE",
  "name": "阿森纳卫冕之路",
  "type": "title",
  "teams": ["ARS"],
  "status": "active",
  "nodes": ["PL-1-ARS-COV", "PL-3-ARS-CHE"]
}
```

## 六、推荐引擎（判据必须可复算，不依赖临场感觉）

### 星级判据

|等级|判据|
|---|---|
|★★★ 必看|六强内战、同城／全国德比、争冠或保级直接对话、故事线关键节点|
|★★ 推荐|争四六分战、名帅对决、旧将反戈、升班马关键战|
|★ 有空可看|中上游对话、新援首秀观察|

命中内置焦点对阵表（双红会、北伦敦德比、国家德比、米兰德比、Der Klassiker、巴黎 v 马赛等）自动进入 ★★★ 候选；故事线到达关键节点自动升一级；关注球队出战自动提一级（最高至 ★★）。

### 睡眠成本分档（北京时间开球）

|档位|开球时间|折算成本|典型|
|---|---|---|---|
|S0 零成本|≤ 22:30|0h|德甲周六早场（21:30）|
|S1 轻度|22:30–00:30|1.0h|英超周六黄金档（22:00–23:00）|
|S2 中度|00:30–02:30|2.5h|德甲晚场、英超晚场|
|S3 重度|02:30–04:00|3.5h|意甲／西甲夜场（02:45–03:00）|
|S4 极限|≥ 04:00|4.5h|冬令时英超周中场（04:00）|

### 夜猫指数公式

```jsx
看点权重 W = star × 10 + 故事线节点加成(0/5/10)
夜猫指数 = W ÷ (1 + 睡眠成本)
```

每周熬夜额度默认 4.0 小时（可调）。以夜猫指数为价值、睡眠成本为重量跑 0-1 背包求解，输出「本周最优组合」。

### 今晚之选产出逻辑

1. 取当日最高星级场为「今晚之选」；星级并列时睡眠成本低者优先，仍并列时故事线节点优先。
2. 其余 ★★ 以上进「今日加餐」。
3. 无球日降级：显示距下一场焦点战倒计时 + 补番推荐（本季已赛高分场次）。国际比赛周整周切换「长草期模式」。

### 雷区预警判据

同时满足以下三条即标注「建议睡觉」，并给出理由文案：睡眠成本 ≥ S3；星级 ≤ ★；不属于任何故事线节点。

## 七、基础功能规格

### 7.1 今晚之选 Hero 卡

字段：对阵、北京时间（大字）＋当地时间（小字）、开球倒计时、星级、三条看点（每条 ≤ 20 字）、夜猫指数标、故事线徽标、转播平台（预留）、夜猫絮语每日一句、海报导出按钮。

### 7.2 本周焦点

跨联赛 Top 5–8 横向卡片。每周一由推荐层按夜猫指数自动生成初稿，人工确认后生效。

### 7.3 赛程日历

日期为主键；联赛与星级双筛选；`tbd` 场次明确标注「时间待定」；已赛场次随每周数据更新补入比分。

### 7.4 关注球队

首次打开引导多选（按联赛分组），可跳过；存本地，不预设任何球队，朋友各自选择互不影响。主队比赛加角标并自动提级，「我的关注」聚合本周主队全部赛程。

### 7.5 雷区预警

「本周」页独立入口，列出本周「建议睡觉」场次及理由。推荐系统的可信度来自敢否定——这直接提升 ★★★ 的含金量。赛季末评「最坑熬夜场次」。

### 7.6 海报一键导出

Canvas 2D 生成 1080×1920 竖版图片并保存相册：今晚之选对阵、北京时间、夜猫指数、三条看点、联赛主题色、夜猫看台品牌位。朋友无需进入小程序即可感知内容，是拉新入口。

### 7.7 夜猫絮语

今晚之选配一句吐槽（写入推荐层），每个比赛日附一条联赛冷知识（`trivia` 字段）。产品有人格，才有人天天打开。

## 八、多人玩法底座：云开发 + 分享卡片

微信云开发（云数据库 + 云函数，免费额度，无自有服务器）：

1. 预测、打卡、狂言、评分直接写入云数据库，openid 天然区分玩家，无需注册。
2. 群内接龙通过**分享卡片携带参数**完成：朋友点开卡片即进入对应玩法页。
3. 结算由云函数自动执行：赛程层 `sc` 比分补录后，盲评猜球、夜猫榜、众评自动出结果，形成权威总榜。
4. 通过分享卡片的 openGid 可将排行榜限定在群维度，多群互不干扰。
5. 订阅消息由云函数定时触发：开球提醒、竞猜截止提醒（需后台申请模板，未过审则用 ICS 日历导出兜底）。
6. 赛程与推荐层放云数据库：更新数据免发版，打开自动拉新。

**云数据库集合与字段**（v1 范围；v1.5 新增集合届时在本节补充）

|集合|关键字段|说明|
|---|---|---|
|fixtures|同赛程层 schema|全量赛程，仅服务端可写|
|recommendations|同推荐层 schema|焦点战推荐与看点|
|storylines|同故事线层 schema|故事线定义|
|predictions|m（比赛 ID）、uid（openid）、gid（openGid）、nick、pick（胜/平/负）、score（比分猜测，可空）、hash（commit 哈希）、revealed（布尔）、ts|盲评猜球|
|checkins|m、uid、gid、nick、ts|夜猫榜打卡|
|boasts|m、uid、gid、nick、text（≤40 字）、ts、result（应验／翻车，结算后写回）|德比法庭|
|users|uid、nick、关注球队、熬夜额度|圈内昵称与偏好|

**权限规则（盲评保密性的根基）**：predictions／checkins／boasts 客户端**只写不读**，读取一律经云函数中转；截止时间（各场开球时刻）前云函数只返回哈希不返回明文，截止后返回明文并校验哈希一致才计分。fixtures／recommendations／storylines 客户端只读。

**圈内昵称**：首次参与玩法时自填（写入 users 集合），排行榜显示昵称而非微信名——免授权弹窗，也更有圈子感。

**云函数清单**

|函数|触发|职责|
|---|---|---|
|settleMatches|比分补录后（每周一，手动触发）|读 sc，结算 predictions 与 boasts，写回积分与应验标记|
|weeklyReport|定时（周一 10:00）|生成周榜、修仙战报、透支结算快照|
|pushReminders|定时（每 15 分钟扫描）|开球提醒与竞猜截止提醒（订阅消息）|
|readBoard|客户端调用|按 gid 返回排行榜，截止前脱敏|

**防偷看**：盲评猜球与赛季预言家的封存采用 commit-reveal——截止前提交加盐哈希，截止后亮出原文，云函数校验一致才计分。

**降级方案**：云开发开通前，回退分享码机制（本地生成 Base64 码、群接龙汇总结算）。

## 九、v1 玩法详设

### 9.1 夜猫指数（熬夜预算）

- 「本周」页顶部：本周额度（默认 4.0h，可调）、最优组合、成本合计与看点覆盖率，调额即时重算。
- 最优组合以夜猫指数为价值、睡眠成本为重量跑 0-1 背包，纯前端计算。
- 给出「若只熬一场，选这场」备选。
- 每周一结算上周实际透支量，超支时自动收紧本周建议额度并提示。

### 9.2 故事线连续剧

- 比赛卡显示所属故事线徽标；详情页为时间轴：已发生节点显示结果，未来节点显示倒计时。
- 看点文案从故事线派生，人工只做润色——这是看点可维护性的根本解法。
- 故事线到关键节点自动升星，不懂联赛的朋友也知道该关心什么。

**初始故事线清单**

|故事线|类型|说明|
|---|---|---|
|阿森纳卫冕之路|争冠|卫冕冠军，社区盾 3-0 胜曼城开局|
|拜仁连霸|争冠|上季第 34 座德甲冠军后继续卫冕|
|巴黎六连冠|争冠|五连冠在手|
|世界杯后遗症|全联赛|本季独有：世界杯刚结束，赛季初阵容疲劳与轮换是核心变量|
|升班马生存战|保级|英超考文垂、赫尔城等|
|跨联赛金靴竞速|数据|五大联赛射手榜并列追踪|
|名帅下岗倒计时|悬念|连败达阈值触发提醒|
|博彩广告禁令首季|背景|英超自本季起禁止胸前博彩赞助|
|西甲／意甲争冠线|争冠|待补充：需核实上季冠军与本季格局|

### 9.3 德比法庭

- ★★★ 场次赛前开放留言：每人一句狂言（≤ 40 字），写入云数据库并可分享进群。
- 比分补录后自动把结果贴在发言旁，标注「应验／翻车」——嘴炮有存档。
- 赛季末统计「最准之口」与「最铁嘴皮」。

### 9.4 盲评猜球

- 范围：仅每周推荐场（5–8 场），不覆盖全量——填写只需一两分钟，焦点场才有讨论热度。
- 计分（默认规则，上线前可调）：猜中胜平负 3 分，猜中比分再 +2；命中「冷门预警」场次翻倍。
- 盲评：commit-reveal 封存，结算前互不可见，防抄答案。
- 结算：比分补录后云函数自动出周榜 + 赛季总榜；每周一战报可分享进群。

### 9.5 夜猫榜（修仙打卡）

- 凌晨档（S2 及以上）开球后 30 分钟内可打卡「我在修仙」。
- 统计修仙时长与场次，连续打卡设小加成。
- 每周生成修仙战报（榜单 + 最狠一夜），可分享进群。

### 9.6 盲盒开球

- 随机抽一场今晚比赛：只显示看点标签与睡眠成本，对阵隐藏，揭晓才知道是谁。
- 可限定条件：仅黄金档、星级下限。
- 群里同抽同看，制造共同话题；治选择困难。

## 十、后续版本玩法

### v1.5（9 月国际比赛日前）

- **奶茶债本**：竞猜积分绑真实赌注（如末位请奶茶），自动记账「谁欠谁一杯」，月末结算。
- **毒奶指数**：统计每人反向准确率，设「反向操作大师」称号——猜得最错的人也有荣誉。
- **搭子雷达**：各自设置「今晚能熬到几点」，算出每场球谁可能在线。
- **赛后众评**：赛后 24h 内打「值回熬夜指数」（1–10 分），聚合出小圈子均分，沉淀「我们眼中的十大战役」。
- **赛季预言家**：第 1 轮前锁定各联赛冠军、英超前四、降级队、金靴，commit-reveal 封存，赛季末一次结算。
- **观赛徽章**：打卡／竞猜行为解锁「德比见证者」「修仙宗师」等，可分享。
- **补番房与剧透屏蔽**：错过的高分场次进补番房；默认隐藏已赛比分，点「我要剧透」才展开。

### v2（赛季中后段）

- **观赛热力图**：整季日历格子，看过的染色、熬夜的加深。
- **赛季年鉴**：末轮自动生成观赛数据与奖项，一键出图发群。
- **数据 API**：云函数定时拉取免费数据源，自动同步赛程调整与比分，结算彻底免维护。

## 十一、技术方案

- **落地形态**：微信小程序（WXML/WXSS/JS）；数据层与逻辑层（推荐引擎、背包求解、结算判定）与平台无关，可先在 HTML 原型验证。
- **发布方式**：体验版，免上架审核；朋友加为体验成员扫码即用。个人主体注册免费；体育数据类目对个人主体有限制，体验版路径可规避，体验成员上限以官方为准。
- **数据**：赛程与推荐层放云数据库，更新免发版；wx.Storage（按小程序 ID 持久，上限 10MB）存个人状态与离线缓存。
- **渲染**：默认只渲染当前周视图，全量赛程按需渲染。
- **海报**：Canvas 2D + 保存相册，iOS 与 Android 双端实测。
- **推送**：订阅消息（云函数定时触发）；模板未过审时 ICS 日历导出兜底。
- **备份**：单文件 HTML 版保留，作为离线兜底与跨平台出口。
- 深色配色，移动端优先，各联赛主题色区分。
